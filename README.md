Este proyecto es un prototipo funcional de un sistema de crédito enfocado en la evaluación de viabilidad crediticia y la gestión de pagos, con el objetivo de brindar claridad y control al usuario durante todo el ciclo del crédito.

Objetivo

Ofrecer una herramienta sencilla que permita:
- Determinar si un crédito es viable o no.
- Simular pagos mensuales y monto total a pagar.
- Calcular adelantos y saldo restante.
- Informar al usuario sobre el impacto de no pagar a tiempo.
- Automatizar recordatorios de pago mediante Google Calendar.

Funcionalidades principales
- Evaluación básica del crédito según ingresos y gastos.
- Cálculo de cuotas y plazos.
- Simulación de pagos adelantados.
- Mensajes claros sobre consecuencias de mora.
- Integración con Google Calendar para fechas de pago.
